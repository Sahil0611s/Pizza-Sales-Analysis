# Pizza Sales Data Analysis & Interactive Dashboard

## Project Overview
This project presents an end-to-end data analysis solution for a pizza restaurant chain to analyze business KPIs, sales trends, and product performance.

The analytical workflow includes:
1. **SQL Analysis & Documentation:** Writing MySQL queries to extract critical business metrics, complete with query logs and execution output screenshots.
2. **Power BI Visualizations:** Designing an interactive 2-page executive dashboard featuring custom slicers, seamless page navigation, and key business insights.

## Repository Contents
- **Pizza_Sales_Dashboard.pbix** — Interactive 2-page Power BI Desktop dashboard (Home & Best/Worst Sellers).
- **Pizza_Sales_SQL_Analysis.pdf** — Detailed PDF report containing all SQL execution queries along with result screenshots.

## Tech Stack & Skills
- **Database Querying:** MySQL Workbench (Aggregations, Grouping, Date-Time Functions)
- **Data Visualization:** Power BI Desktop (DAX Measures, Data Modeling, Slicers, Custom Visual Layouts)
- **Reporting:** Microsoft Word / PDF Documentation

## Key Performance Indicators (KPIs)
- **Total Revenue:** 817.86K
- **Total Orders:** 21,350
- **Total Pizzas Sold:** 49,574
- **Average Order Value (AOV):** 38.31
- **Average Pizzas Per Order:** 2.32

## Key Business Insights

### Page 1: Sales Trends & Category Distribution
- **Busiest Days:** Peak order volume occurs on **Thursday (~3.5K orders)** and **Wednesday/Friday**.
- **Peak Months:** Highest sales volume recorded in **July** and **January**.
- **Top Category:** **Classic Category** generates the highest revenue share (**~26.91%**).
- **Preferred Size:** **Large Size Pizzas** account for **~45.89%** of total sales.

### Page 2: Item Ranking (Best & Worst Sellers)
- **Top Revenue Pizza:** *The Thai Chicken Pizza* (43.43K)
- **Top Sold Quantity:** *The Classic Deluxe Pizza* (2.45K units)
- **Lowest Performing Pizza:** *The Brie Carre Pizza* (Lowest revenue ~11.59K & ~480 orders)
